# 凡人打字机 (fr-cli) 使用手册

## 快速开始

- 输入 `/help` 查看所有命令
- 输入 `/tutorial` 开始交互式教程
- 直接输入问题即可与 AI 对话

## 常用命令

- `/model <模型名>` — 切换大模型
- `/key <api_key>` — 设置 API Key
- `/dir <目录>` — 设置工作目录
- `/save <名称>` — 保存当前会话
- `/load <名称>` — 加载历史会话

## 内置 Agent

- `@local <需求>` — 本地系统操作
- `@remote <别名> <需求>` — 远程 SSH 操作
- `@db <别名> <查询>` — 数据库查询
- `@RAG <问题>` — 知识库问答
