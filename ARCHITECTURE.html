03关键子系统 — 6 个高内聚模块

fr-cli 的核心能力由 6 个独立子系统提供,每个都有自己的状态文件、API 和持久化存储。

MasterAgent

~/.fr_cli/master/

自我进化主控。ReAct 循环 + 每 10 次自动反思,失败驱动学习。

  • ReAct 8 步循环
  • failure_hints 注入
  • persona/skills/memory 持久化
  • background 隔离执行

Hermes

~/.fr_cli/hermes/

后台自治任务引擎。目标分解、子任务依赖 DAG、链式执行、独立守护进程。

  • PersistentTaskManager
  • 依赖检测 + 循环保护
  • 沙盒 / autonomous 双模式
  • HTTP API (8765)

Agent Swarm

蜂群协作

并行 / 议会 / 流水线 3 种协作模式,任务单元支持 Agent、工具、命令、MCP、插件。

  • parallel / council / pipeline
  • max_workers 并发控制
  • 任务名格式:agent:/tool:/cmd:/mcp:/plugin:
  • 失败隔离

Dynamic Builder

~/.fr_cli/dynamic_tools/

按需安装依赖并生成工具。LLM 决策 → 依赖安装 → 代码生成 → 自测 → 注册。

  • 需求规划 + 缺口发现
  • 自动 pip install
  • 自测失败回滚
  • Result 风格返回

Web Console

localhost:17890

实时仪表盘。SSE 事件流 + REST API + Prometheus 指标导出 + Bearer 鉴权。

  • /api/events SSE 长连接
  • /agents//run 远程调用
  • /api/metrics (json|prom|summary)
  • EventBus 桥接

v3 EventBus

fr_cli/core/events.py

贯穿全局的事件总线。优先级排序 + wildcards + once + 异常隔离,自动驱动指标与日志。

  • 优先级 + 通配符
  • sync / async 双模
  • V2Events / V2HookEvents 兼容层
  • UsageTracker / ErrorLedger 自动订阅

05安全机制 — 4 层防护 + 自治模式

所有危险操作都经过安全确认,4 个 sec_* 类别独立控制,可分级永久放行。

四阶确认 (Y/A/F/N)

每次危险操作弹出 4 选项:
Y 仅此 · A 本轮 · F 永久 · N 拒绝

按 [F] 只放行当前 sec_* 类别,不波及其他(自 v2.4.4)。

VFS 路径沙盒

所有文件操作通过 Path.resolve() 后落在 allowed_dirs 内。

防止 ../ 逃逸 + 防止 /foo 误匹配 /foo-bar。

自治模式

manual 每次询问 · sandbox_auto 沙盒自动放行 · full_auto 全部放行(危险)。

Hermes 默认 sandbox,后台任务安全运行。

SSRF / 注入防护

Web 抓取拦截 localhost / 私有 IP 段。
邮件头过滤 \r \n。
SSH 用 paramiko 替代 shell=True。
配置写入用 tempfile + os.replace 原子写。
